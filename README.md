# ABC Kids - Learn & Play 🎈

A colorful, interactive, and offline-ready Android application created for young children aged 2-6 to learn alphabets, numbers, colors, and animals with voice TTS support and fun matching games.

---

## 🌟 Features Implemented

1. **Bright & Child-Friendly Home Screen**:
   - 4 large primary buttons: **ABC**, **123**, **Colors**, **Animals**.
   - 1 bonus game button: **Match Game**.

2. **🔤 ABC Module**:
   - Complete 26 English letters (A–Z) with big colorful cards.
   - Interactive pop-up card for each letter showing the letter sound, object name, and object picture (e.g., *A for Apple*, *B for Ball*).

3. **🔢 123 Module**:
   - Numbers 1 to 20 with interactive cards.
   - Shows matching counts of objects (e.g., 3 ⭐ Stars, 5 🚗 Cars).

4. **🎨 Colors Module**:
   - 10 common colors (Red, Blue, Green, Yellow, Orange, Purple, Pink, Brown, Black, White).
   - Dynamic colorful backgrounds with high contrast text and voice pronunciation.

5. **🦁 Animals Module**:
   - 15 common animals with names and cute emoji icons (Lion, Elephant, Monkey, Panda, Rabbit, etc.).

6. **🧩 Match the Letter Game**:
   - Interactive educational game where children match the correct letter to the displayed target picture.
   - Live score tracking with star rewards 🌟 and encouragement voice feedback.

7. **🗣️ Android Text-to-Speech (TTS)**:
   - Voice pronunciation built-in for letters, numbers, colors, and animal names tuned to a kid-friendly rate and pitch.

8. **📢 AdMob Banner Integration**:
   - Sticky AdMob banner ad at the bottom of every screen (using Google AdMob official test ID `ca-app-pub-3940256099942544/6300978111`).

9. **📱 Offline & Lightweight**:
   - Pure HTML5 + CSS3 + JS architecture, totally offline and packaged into a native Android WebView app under 5 MB.
